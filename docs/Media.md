# Media

## Video demo

The project owner supplied a screen recording of MyBar in use on November 5,
2026. The public demo retains the full clip and original 1078 × 1252 resolution,
converted to H.264 MP4 at 30 fps for playback. Duration is approximately
110.7 seconds. No cuts, crops, overlays or narration were added. The supplied
recording has no audio track. It shows the owner's desktop and live on-screen
state; it is separate from the sample-data graphics described below.

The video is hosted as the `MyBar-screen-recording-demo.mp4` release asset.
`docs/media/screen-recording-poster.jpg` is a still extracted from the same clip.
The earlier generated demos are not included.

## Graphics and screenshots

The banner, feature graphic and social card use custom geometric layouts,
existing app artwork and native AppKit view exports. Screenshots render the
actual build 20 views with sample metrics and audio state. They are interface
previews, not desktop captures or evidence of hardware actions.

The sample-data screenshot exports do not capture a personal desktop, browser
tabs, location, real app history or session data. The example network address is reserved for documentation. The app's
existing artwork is used unchanged.

Files in `docs/media/`:
- `hero.png`: repository banner, 1600 × 1000.
- `features.png`: feature graphic, 1600 × 1120.
- `social-preview.png`: sharing graphic, 1280 × 640.
- `system-overview.png`: System overview screenshot.
- `network-apps.png`: Network and apps screenshot.
- `sound-controls.png`: Sound controls screenshot.
- `system-insights.png`: Insights screenshot.
- `trackpad-settings.png`: Experimental settings screenshot.
